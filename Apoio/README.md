# 📁 Pasta de Apoio | Domínio Corporal

Esta pasta reúne todos os arquivos de **suporte, scripts técnicos, bancos de dados brutos e documentações de bastidores** do projeto de treinamento.

> **Nota:** Os arquivos de consulta diária (App de Treino, Planilha Excel e Visualizador Web) estão localizados diretamente na raiz do projeto para acesso rápido com 1 clique.

---

### 📂 Conteúdo desta Pasta:

1. **`gerar_planilha_prontuario.py`**
   - Script Python (`openpyxl`) responsável por compilar e gerar a planilha Excel oficial (`PRONTUARIO_E_HISTORICO_GUILHERME_LEMOS.xlsx`) no padrão visual de mestrado da USP (LaCiDH).

2. **`historico_treinos.json` & `historico_treinos.csv`**
   - Bases de dados consolidadas com o registro estruturado de todas as sessões realizadas, cargas, sensações e avaliações do coach.

3. **`prontuario_aluno_guilherme_lemos.md`**
   - Prontuário técnico completo e diário de bordo do atleta em formato Markdown, contendo diretrizes articulares, metas e condutas clínicas.

4. **`perfil_atleta.md`**
   - Ficha de diretrizes biomecânicas personalizadas (joelho, ombro, tendão de Aquiles).

5. **`treino_semanal.md`**
   - Prescrição semanal detalhada com periodização de cargas e blocos de treino.

6. **`github_token.txt`**
   - Token e instruções técnicas de versionamento no repositório remoto Git.
